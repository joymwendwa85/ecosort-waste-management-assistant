# ecosort-waste-management-assistant
An AI waste management assistant using CNN image classification, text classification, and recycling policy retrieval.

## Overview
EcoSort is a waste management project that helps people identify waste and learn how to dispose of it correctly. It uses image classification, text classification, and recycling policy documents to provide disposal guidance.

## Objectives
- Identify waste materials from images using a Convolutional Neural Network (CNN).
- Classify waste based on text descriptions.
- Retrieve relevant recycling and disposal information from policy documents.
- Combine these features into one waste management assistant.

## Technologies Used
- Python
- Pandas and NumPy
- TensorFlow/Keras
- Scikit-learn
- Matplotlib and Seaborn
- Jupyter Notebook

## Project Files
- `waste_management_summative.ipynb` – Main project notebook.
- `waste_descriptions.csv` – Waste descriptions dataset.
- `waste_policy_documents.json` – Recycling and disposal policy documents.

## How to Run
1. Clone or download this repository.
2. Install the required Python libraries.
3. Make sure the dataset files and image dataset are in the correct locations.
4. Open the notebook in Jupyter Notebook and run the cells in order.

## Conclusion
This project combines machine learning and policy information to support better waste sorting and disposal. It aims to help people make better waste management decisions.
